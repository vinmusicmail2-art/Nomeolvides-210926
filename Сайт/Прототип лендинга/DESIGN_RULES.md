# Правила работы с макетом

- Рабочая основа: `landing-concept-WORKING-BASE.png`.
- Не менять основу без отдельного прямого указания пользователя.
- Выполнять только названное пользователем изменение.
- Не добавлять самостоятельно значки, стрелки, декоративные элементы, линии, иллюстрации или новые блоки.
- Не двигать и не менять другие элементы страницы, если это не поручено отдельно.
- Каждый новый вариант сохранять отдельным версионным файлом; рабочую основу не перезаписывать.
